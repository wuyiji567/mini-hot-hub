# 今日热搜 · 前端设计文档 Final

> 本文档基于 `DESIGN_V2.md` 定稿，目标是把视觉方向、产品范围和前端落地规则统一成可执行规格。原 `DESIGN.md` 和 `DESIGN_V2.md` 保留不动。

## 1. 设计概述

### 1.1 项目定位
「今日热搜」是一个 AI 增强的多平台热搜聚合网站。前端设计的核心目标是在信息密度与阅读舒适度之间取得平衡，让用户能在 3 分钟内快速掌握全网热点。

### 1.2 设计语言
- **风格**：深色科技风、信息密度高、兼具科技感与阅读舒适度
- **基调**：深色背景 + 青色强调，专业且沉浸
- **参考**：AIHOT 的信息层级感 + 深色 Dashboard 风格
- **布局**：左侧固定导航栏（200px）+ 右侧内容区，三视图切换（首页 / 个性推荐 / 平台）

### 1.3 Final 设计边界

- **目标态**：三视图架构（首页 / 个性推荐 / 平台）+ 左侧固定导航栏 + 顶栏。
- **当前实现差距**：当前 `mini-hot-hub-frontend` 仍是单页流式结构，已有 `TopBar`、`HeroSection`、`AIRecommendPanel`、`FilterBar`、`PlatformGrid` 等组件；Final 设计以目标态为准，后续实现需要拆出 `Sidebar` 和三个视图容器。
- **MVP 平台范围**：微博、知乎、B站、澎湃新闻、36氪、虎扑、GitHub、今日头条共 8 个核心平台；抖音为可降级平台。小红书不纳入本期设计范围。
- **平台标识**：前端统一使用 `weibo`、`zhihu`、`bilibili`、`thepaper`、`kr36`、`hupu`、`github`、`toutiao`、`douyin`；若后端沿用 `36kr`，需在接口层映射为 `kr36` 后再进入 UI。
- **MVP 个性化范围**：无需登录，不做真实用户画像；个性推荐基于预设关注标签和 AI 推荐结果。

### 3.2 组件详细设计

#### 侧边栏 (Sidebar)
- **位置**：`position: fixed; left: 0; top: 0; bottom: 0; width: 200px`
- **背景**：`--bg-sidebar (#0f1520)` + 右侧 1px 边框 + 深色投影
- **结构（自上而下）**：
  - 品牌标识：30px 渐变方块 Logo + "今日热搜" 等宽字体
  - 搜索框：圆角药丸输入框（占位）
  - 导航区：首页 / 个性推荐 / 平台（图标 + 文字，激活项青色高亮 + 半透明背景）
  - 热门标签：科技 / 娱乐 / 体育 / 财经 / 社会（主推 5 类，彩色圆点 + 文字，点击跳转个性推荐视图并筛选）
  - 页脚：声明文字
- **移动端**：默认 `transform: translateX(-100%)` 隐藏，汉堡按钮触发展开 + 遮罩层

#### 顶栏 (TopBar)
- **位置**：`position: sticky; top: 0; z-index: 50`
- **背景**：`rgba(11,15,25,0.92) + backdrop-filter: blur(20px)`
- **高度**：约 52px
- **左侧**：移动端汉堡按钮 + 页面标题（随视图切换变化）+ 副标题
- **右侧**：日期时间（等宽字体青色）+ 刷新按钮

#### 今日最热轮播 (HotCarousel)
- **位置**：首页视图最顶部
- **容器**：圆角 14px + 1px 边框，`overflow: hidden`
- **每张幻灯片**：
  - 全宽背景图（高度 300px，桌面端；220px，移动端）
  - 底部渐变遮罩（从透明到 90% 不透明深色）
  - 分类标签：青色药丸（如「科技 · AI」），带发光阴影
  - 事件标题：22px 粗体白色
  - AI 热门原因：12px 次要文字，左侧 2px 青色竖线 + 半透明背景区块
  - 底行：热度值（玫红色）+ 讨论平台数 + 趋势标签
- **交互**：两侧**窄长方形箭头按钮**（约 44×64px，圆角，默认接近透明约 15% 不透明度，hover 加深至 65%），不遮挡文字内容；底部圆点指示器；5 秒自动轮播
- **降级**：AI 不可用时隐藏或显示占位

#### 热点速览 (QuickNews)
- **位置**：今日最热下方
- **布局**：2 列网格，每页 2 张卡片
- **每张卡片**：与今日最热同为图片覆盖式（图高 160px + 底部渐变遮罩 + 标签/标题/AI 摘要/热度）
- **交互**：两侧窄长方形箭头按钮翻页（样式同今日最热，接近透明、不遮挡文字）

#### 图片策略 (Image Policy)
- **图片来源优先级**：后端返回 `imageUrl` > 平台默认封面 > 分类默认封面 > 通用默认封面；AI 不直接编造图片 URL。
- **版权边界**：MVP 不抓取来源站正文图片；优先使用可公开展示的自有图片、开源图库或项目内默认图片。
- **裁切规则**：所有图片使用 `object-fit: cover; object-position: center`，今日最热比例约 16:6，热点速览约 16:9，个性推荐约 16:7。
- **可读性保障**：图片卡片必须覆盖底部渐变遮罩，文字区域背景不透明度在 70%~90% 之间；浅色图片需额外叠加暗色遮罩。
- **失败兜底**：图片加载失败时替换为分类默认封面，不显示破图图标；默认封面也失败时使用纯色渐变背景。

#### 轮播可访问性 (Carousel A11y)
- 自动轮播默认 5 秒切换，用户 hover、focus、点击箭头或点击圆点后暂停自动播放。
- 左右箭头按钮必须可通过键盘聚焦，并提供明确 `aria-label`（如「上一条今日最热」「下一条热点速览」）。
- 圆点指示器必须提供当前状态与目标序号说明（如「查看第 3 条，共 5 条」）。
- 支持键盘左右方向键切换当前轮播。
- 当系统设置 `prefers-reduced-motion: reduce` 时，关闭自动轮播和非必要动画。

#### 综合热榜 (RankingList)
- **位置**：首页视图最下方
- **布局**：2 列并排列表，序号连续不重复（左列 1~10，右列 11~20）
- **每条**：排名序号（1~3 金银铜高亮 5px 圆角徽章）+ 标题 + 平台小圆点 + 热度值 + 趋势箭头

#### 个性推荐 (InterestView)
- **筛选栏**：药丸按钮组（全部 / 科技 / 娱乐 / 体育 / 财经 / 社会 / 游戏 / 教育 / 汽车 / 国际 / 生活 / 其他），激活项青色填充；移动端横向滚动
- **内容区**：纵向排列大卡片，样式与今日最热一致
  - 推荐原因标签：「你关注 · XX」（青色）或「相似主题」（紫色）
  - AI 推荐理由：青色竖线高亮区块

#### 平台卡片 (PlatformCard)
- **布局**：3 列网格（桌面）/ 2 列（平板）/ 1 列（手机）
- **头部**：平台 Logo（30px 圆角方块，平台专属色）+ 平台名 + 榜单名 + 状态徽章
- **内容区**：默认展示 Top 10 热搜列表，排名 1~3 金银铜高亮；如数据充足，可提供 "查看更多" 展开至 Top 15~20。验收口径以展开后 Top 15~20 为准，平台数据不足时按实际返回条数展示。
- **底部**：查看完整榜单链接 + 更新时间

## 5. 交互设计

### 5.1 按钮/链接状态

| 状态 | 效果 |
|------|------|
| 默认 | 正常显示 |
| Hover | 轻微上移 (-1px) + 边框/颜色变化 |
| 激活 | 保持样式 |
| 禁用 | 降低透明度 + 无交互 |

### 5.2 刷新按钮

- 点击后进入 loading 状态 (SVG 旋转动画)
- 禁用按钮防止重复点击
- 命中缓存但请求成功：显示 Toast "已刷新：当前展示缓存内的最新热榜"
- 全量刷新成功：显示 Toast "数据已更新"
- 部分平台失败：保留成功平台数据，对失败平台显示降级态，Toast "部分平台暂时不可用"
- AI 失败但基础热榜成功：隐藏 AI 区域或显示 AI 占位，Toast "AI 推荐暂时不可用，热榜仍可浏览"
- 网络或后端失败：保留旧数据，显示 Toast "刷新失败，显示的是之前的数据"

### 5.3 标签筛选

- 点击标签按钮切换激活状态
- 所有平台卡片实时过滤显示匹配条目
- 无匹配时显示空状态提示
- 筛选状态更新副标题文案

### 5.4 回到顶部

- 点击平滑滚动到页面顶部

### 6.1 页面加载

- 骨架屏或渐进式加载
- 各卡片按顺序淡入 (stagger 100ms)

### 6.2 交互动画

```css
/* 通用过渡 */
transition: transform 160ms ease, border-color 160ms ease, background 160ms ease, color 160ms ease;

/* Hover 上浮 */
transform: translateY(-1px);

/* 刷新按钮旋转 */
animation: spin 700ms linear infinite;

/* Toast 滑入 */
transition: opacity 180ms ease, transform 180ms ease;
transform: translateY(0); /* show */

```

## 7. 异常状态设计

### 7.1 单平台错误

- 卡片头部状态标签变为 "降级" (红色)
- 内容区显示错误提示框
- 提供重试按钮
- 不影响其他卡片显示
- 若该平台存在过期缓存，可继续展示旧数据，并在卡片头部标注 "可能过期"

### 7.2 AI 不可用

- 今日最热、热点速览、个性推荐隐藏或显示占位提示
- 综合热榜展示接口顶层 `ranking` 数据，不依赖 AI 必须可用；若 `ranking` 为空，则隐藏综合热榜并提示 "综合热榜暂时不可用"
- 分类标签显示为空数组，前端不展示空标签容器
- 基础热搜正常展示

### 7.3 全局错误

- 显示全局错误页或重试按钮

### 7.4 空数据

- 平台返回成功但列表为空时，平台卡片显示 "暂无数据"，不使用错误态样式。
- 标签筛选后无结果时，在当前区域显示空状态，不清空筛选栏。
- 所有平台均无数据时，显示全局空状态，并提供刷新按钮。

## 9. 技术实现要点

### 9.1 数据流

1. 页面加载时请求 `GET /api/hot`
2. 数据存入 React State
3. 各组件从 State 读取并渲染
4. 刷新按钮重新请求数据
5. 标签筛选为纯前端过滤

### 9.2 性能优化

- 使用 `React.memo` 优化卡片重渲染
- 标签筛选使用 `useMemo` 缓存过滤结果
- 图片/图标使用 SVG 内联，减少请求
- 支持虚拟滚动（如果列表过长）

### 9.3 可访问性

- 所有按钮有 `aria-label`
- 区域有 `aria-labelledby` 关联标题
- 状态更新使用 `aria-live="polite"`
- 颜色对比度符合 WCAG 2.1 AA 标准
