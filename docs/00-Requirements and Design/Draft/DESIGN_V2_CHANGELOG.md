# DESIGN_V2 修改记录

本文记录 `DESIGN.md` 到 `DESIGN_V2.md` 的主要调整点。设计正文只保留最终规格，修改原因和变更历史放在本文件中维护。

## 变更清单

- 复制 `DESIGN.md`，新增 `DESIGN_V2.md`，原文档保留不动。
- 明确 V2 是目标态前端设计文档：目标为左侧导航栏 + 顶栏 + 首页 / 个性推荐 / 平台三视图。
- 补充当前实现差距：当前 `mini-hot-hub-frontend` 仍是单页流式结构，后续需逐步拆出 `Sidebar` 和三个视图容器。
- 统一 MVP 平台范围为 8 个核心平台 + 1 个可降级平台：
  - 核心平台：微博、知乎、B站、澎湃新闻、36氪、虎扑、GitHub、今日头条。
  - 可降级平台：抖音。
  - 本期不做：小红书。
- 今日头条已加回 V2 平台范围、平台配色表、平台标识枚举和参考项目差异表。
- 补充平台标识规则：前端统一使用 `kr36`，如后端沿用 `36kr`，需在接口层映射后再进入 UI。
- 统一标签体系：固定为科技、娱乐、体育、财经、社会、游戏、教育、国际、生活、其他；影视、汽车不作为独立 V2 标签。
- 补充图片策略：明确图片来源优先级、版权边界、裁切规则、文字可读性保障和加载失败兜底。
- 补充轮播可访问性：明确暂停自动播放、键盘操作、`aria-label`、圆点状态说明和 `prefers-reduced-motion`。
- 细化刷新反馈：区分缓存命中、全量成功、部分平台失败、AI 失败和网络/后端失败。
- 细化异常与空状态：补充过期缓存、AI 不可用、综合热榜兜底、平台空列表和全局空数据规则。
- 更新文件结构：从泛化的 `frontend/` 改为当前真实目录 `mini-hot-hub-frontend/`，并标注 V2 新增组件与迁移路径。
