# 今日热搜 PRD V2 修改记录

修改日期：2026-06-05

## 文件

* 源文件：`PRD.md`
* 新版本：`PRD_V2.md`
* 修改记录：`PRD_V2_CHANGELOG.md`

## 修改点

1. 增加 V2 修订说明
   * 在文档标题下说明 `PRD_V2.md` 是基于 `PRD.md` 复制生成。
   * 明确原 `PRD.md` 保持不变。

2. 收敛 MVP 个性化口径
   * 将「个性推荐页基于 AI 提供个性化内容卡片」调整为「基于预设兴趣标签和 AI 推荐结果提供主题化内容卡片」。
   * 明确首版不使用真实用户画像，不声称基于登录用户行为或相似用户协同过滤。

3. 明确首屏加载与 AI 降级关系
   * 增加「首屏优先展示基础热榜，AI 区域允许异步补齐或降级」。
   * 在产品体验指标中补充：首屏基础热榜不等待 AI 完成。

4. 统一平台 source 枚举
   * 将 36氪平台标识统一为 `kr36`。
   * 补充说明：如后端或第三方源返回 `36kr`，进入业务响应前需映射为 `kr36`。
   * 追加 `toutiao` 作为今日头条平台标识。

5. 收敛标签筛选作用范围
   * 取消「首页顶部承担全局标签筛选」的描述。
   * 明确平台视图负责完整平台热榜标签筛选。
   * 明确个性推荐视图负责推荐内容标签筛选。
   * 明确侧边栏热门标签点击后跳转至个性推荐视图并筛选对应标签。

6. 统一 AI 响应契约
   * 将成功响应示例中的旧字段 `level`、`reason`、`sentiment`、`relatedItems` 移除。
   * 改为使用 `featured` 表示「今日最热 + 热点速览」。
   * 保留 `recommendations` 表示个性推荐。
   * 增加顶层 `ranking` 表示基础综合热榜，避免它依赖 AI 可用性。

7. 明确 AI 不可用时的接口表现
   * `ai.available` 为 `false` 时，`featured` 和 `recommendations` 返回空数组。
   * `ranking` 仍可返回基础聚合结果。
   * 补充说明：AI 不可用仅影响「今日最热」「热点速览」「个性推荐」等 AI 区域。

8. 修正平台示意图残留项
   * 首次 V2 中曾将页面结构示意图中残留的「头条」移出；后续按技术风险判断已将今日头条重新加入 MVP 核心平台。

9. 补充缓存与 AI 延迟策略
   * 在缓存机制中说明：首屏可先返回命中的基础热榜缓存，AI 数据为空或延迟补齐时前端展示降级态。

10. 补充合规和版权边界
    * 增加图片版权策略：MVP 不抓取来源站正文图片，优先使用自有图片、开源图库、平台默认封面或分类默认封面。
    * 增加数据抓取边界：控制抓取频率，不绕过登录、付费墙或明显反爬限制。
    * 增加下架处理：收到权利人或平台反馈后，可移除对应链接、标题、图片或平台数据源。

11. 将今日头条加回 MVP 核心平台
    * 按「技术上没有明显难点则纳入」的判断标准，将今日头条作为第 8 个核心平台加入。
    * 产品概述、MVP 定义、平台视图、source 枚举、页面结构示意图和工程验收指标均同步为 8 个核心平台。
    * 抖音仍保持「尽力接入，可降级」状态，不计入核心平台稳定展示要求。

12. 统一个性推荐筛选栏标签枚举
    * F1d 筛选栏从「全部 / 科技 / 财经 / 影视 / 汽车」改为使用固定 10 类标签枚举（全部 / 科技 / 娱乐 / 体育 / 财经 / 社会 / 游戏 / 教育 / 国际 / 生活 / 其他），与 DESIGN_V2 标签体系对齐。
    * 「影视」「汽车」不作为独立标签，需映射到固定枚举（影视→娱乐，汽车→财经或生活）。

## 后续建议

* 后续若更新 `TECH_DESIGN.md`，建议同步采用 `featured`、`recommendations`、顶层 `ranking` 的接口结构。
* 后续若更新前端类型定义，建议将旧的 `AIRecommendation` 拆为 `AIFeatured` 与 `AIRecommend`，并增加 `RankingItem`。
