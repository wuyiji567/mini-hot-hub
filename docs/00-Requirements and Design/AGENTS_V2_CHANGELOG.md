# 今日热搜 AGENTS V2 修改记录

## 基本信息

- 原文件：`AGENTS.md`
- 新文件：`AGENTS_V2.md`
- 修改日期：2026-06-06
- 修改目的：在保留原开发指令的基础上，生成一份更贴合 PRD 和 Tech Design 分阶段策略的 V2 版本，明确它服务于 **MVP 第一阶段开发**。

## 修改背景

原 `AGENTS.md` 已经基本符合项目方向，但存在几处容易让 AI 开发时跑偏的地方：

- 项目概述里写了完整三视图和 AI 区域，但版本范围又要求第一阶段不做 AI，容易产生范围冲突。
- `HotResponse` 使用了 `AIFeatured` 和 `AIRecommend`，但原文没有定义这两个类型。
- `Source` 枚举包含 9 个平台，但第一阶段实际只接入 4 个平台，需要说明类型范围和实现范围的区别。
- Tech Design 建议目录为 `client/ + server/`，但当前仓库已经存在 `mini-hot-hub-frontend/`，需要避免 AI 重复新建前端项目。

## 具体修改

### 1. 明确 V2 文件定位

将标题从：

```md
# 今日热搜 · AI 开发指令
```

修改为：

```md
# 今日热搜 · AI 开发指令 V2
```

并在项目概述中补充说明：本文件是 **MVP 第一阶段开发指令**，目标是先把基础热榜聚合链路跑通。

### 2. 澄清第一阶段不做真实 AI 内容

在项目概述中补充：

- 第一阶段首页只实现综合热榜和平台热榜基础浏览。
- 「今日最热」「热点速览」「个性推荐」可以先保留入口、占位态或隐藏真实内容。
- 第二阶段再接入 AI 后补齐这些区域。

这样可以避免 AI 在第一阶段直接实现依赖 AI 的轮播、推荐和推荐理由。

### 3. 对齐 PRD 和 Tech Design 的分阶段关系

在版本范围中补充说明：

- PRD 中的完整 MVP 包含 8 个核心平台和 AI 增强体验。
- Tech Design 将开发拆成两个阶段。
- 第一阶段只交付稳定基础热榜。
- 第二阶段再补齐 PRD 完整 MVP。

这可以帮助后续开发时理解：`AGENTS_V2.md` 不是否定 PRD，而是执行 Tech Design 中的第一阶段范围。

### 4. 补充当前前端目录处理方式

在项目结构后补充：

- 如果当前仓库已经存在 `mini-hot-hub-frontend/`，第一阶段可以先沿用该目录继续开发。
- 不要重复新建前端项目。
- 后续需要统一结构时，再重命名或迁移为 `client/`。
- 后端仍按 `server/` 新建。

这是为了避免仓库中同时出现两个前端目录，导致代码分散。

### 5. 补充 Source 枚举和第一阶段实现范围的区别

在 `Source` 类型后补充注释：

```ts
// 第一阶段 Source 类型保留完整枚举，但 services 只实现：
// weibo / zhihu / bilibili / github。
// 其余平台不进入默认聚合，第二阶段或未来版再接入。
```

这样既保留了完整接口契约，又明确第一阶段不需要实现所有平台。

### 6. 补全 AI 相关类型

新增了两个类型定义：

- `AIFeatured`
- `AIRecommend`

原因是 `HotResponse` 中引用了这两个类型。如果不补全，AI 或开发者实现时可能自行猜字段，导致和 Tech Design 不一致。

### 7. 收紧接口规范

在接口规范中补充：

```md
- 第一阶段 `/api/hot` 默认只聚合 `weibo` / `zhihu` / `bilibili` / `github`
```

这样可以防止开发时误以为 `/api/hot` 第一阶段就必须返回 8 个核心平台或抖音。

### 8. 补充设计降级说明

在设计规范中补充：

```md
- 第一阶段如保留「今日最热」「热点速览」「个性推荐」区域，只显示轻量占位或不可用提示，不展示伪造 AI 内容
```

这条用于约束前端：第一阶段可以保留页面结构，但不能用假 AI 内容冒充真实 AI 结果。

## 修改后的效果

`AGENTS_V2.md` 现在更清楚地区分了三件事：

- **PRD 完整目标**：8 个核心平台 + AI 增强体验。
- **Tech Design 阶段拆分**：第一阶段先做稳定基础热榜，第二阶段补 AI 和剩余平台。
- **AGENTS V2 执行范围**：只指导 MVP 第一阶段开发，避免一次性实现过多高风险功能。

## 后续建议

正式进入开发时，优先使用 `AGENTS_V2.md` 作为 AI 开发指令。

如果第二阶段开始接入 AI、澎湃、36氪、虎扑、今日头条，可以再创建 `AGENTS_V3.md`，专门记录第二阶段开发范围和新增约束。
